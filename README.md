# App Nacionalidad 🇪🇸

¡Bienvenido a mi proyecto! Esta es una aplicación web tipo Trivia para practicar el examen de nacionalidad española.

## 🚀 Características
- Preguntas de cultura general de España.
- Temporizador de 15 segundos por pregunta.
- Barra de progreso dinámica.
- Guardado de récord histórico (localStorage).
- Preguntas y respuestas aleatorias en cada partida.

## 🛠️ Tecnologías usadas
- React
- Vite
- CSS en línea (Inline styles)

## 💻 Cómo jugar en local
Si quieres probarlo en tu ordenador:
1. Clona este repositorio: `git clone https://github.com/soukaynael12/app-nacionalidad.git`
2. Instala las dependencias: `npm install`
3. Inicia el servidor: `npm run dev`
